# 底座 + 配電（base_power）

分工：機構 session 負責 CNC 本體；本資料夾由「底座 / 支架 / 配電」這邊負責。尺寸座標與 `freecad/v13/06_base_coolant_v13.py` 相同（地板 z=-790，前方 = -y，立柱 x=±517.5）。

## 決定（可推翻）
| 項目 | 決定 | 理由 |
|---|---|---|
| 電控箱位置 | 底座前下方空間，正面開門 | 水箱在後方滑出；前下方空著；馬達線最短；操作者站前方就能維修 |
| 箱體 | 鋼板壁掛箱 940×540×250，IP54，雙開門，斜屋頂，底部穿線板 | 高度受桌面 900 mm 限制，放得下的最大尺寸 |
| 箱體支撐 | 兩根 40×40 橫梁 (y=-500、-330, z -730..-690) 跨在左右低樑之間，箱體螺栓鎖在上面 | 取代原本的低前樑（門會掃到它），同時保留框架剛性 |
| 低環高度 | 低環降到立柱底端（z -730..-690，原 -700..-660） | 多出 30 mm 給箱體 |
| 安裝板 | 880×480×2.5 鍍鋅板 | 見 `panel_layout.png` |
| 散熱 | 估計盤內發熱約 160 W（驅動 3×25 + 變頻器 40 + 電源/接觸器 45）；箱體自然散熱約 100 W (ΔT=10 K) → 加 1 組 24 V 濾網風扇（進風下方、出風上方後側，IP54 濾網）| 估算，待實機量溫度 |

## 要機構 session 配合的事（請確認或反駁）
1. 低前樑 `Base_low_front` 刪除，改為 `Cabinet_rail_1/2`；低環 `LZ` 由 `FLOOR+90` 改為 `FLOOR+60`。
2. 右側導流板（`Guard_side_R`）加一個密封穿線板（M25 護套 ×6），給 X 馬達與感測器線；冷卻水管已在左側。
3. 拖鏈介面：機構側提供每條拖鏈能容納的線（見 `CABLE_LIST.csv`：M01–M07、S01、P01、P02、D02），線從拖鏈起點出來後由我這邊的線槽接到電控箱。
4. 本體與電控箱的間隙：箱體頂 z=-150，上環下緣 z=-130，間隙 20 mm。

## 檔案
- `layout.py` 零件尺寸與排列規則（估算尺寸標 `*`，下單前以廠商圖面確認）
- `build.py` → `panel_layout.svg/.png`、`base_iso.svg/.png`、`CABLE_LIST.csv`、`panel_check.txt`
- `build_step.py`（FreeCAD）→ `base_power.step`、`step_check.txt`（干涉檢查：0 處）
- 重新產生：`python3 base_power/build.py`；`CNC_ROOT=$PWD /opt/freecad/bin/freecadcmd base_power/build_step.py`

## 還沒確認 / 風險
- 所有 `*` 尺寸（斷路器、接觸器、電源、濾波器、MS300、TB40、控制板）是估算，板面實際排列要等零件到貨量尺寸。
- 三菱驅動器上下需要 40 mm：目前上方 40、下方 51（依手冊 3.x，電工複核）。
- 驅動器 2 公斤級重量與振動：板子固定點與底座錨固未計算。
- 線種、線徑、漏電斷路器：電工決定（見 `electrical/electrician_checklist.pdf`）。
- 預製伺服線型號（MR-PWS1CBL、MR-J3ENCBL、MR-BKS1CBL）憑記憶，需對照三菱型錄。
- 機構側拖鏈與穿線板位置尚未對齊（上面第 2、3 點）。
