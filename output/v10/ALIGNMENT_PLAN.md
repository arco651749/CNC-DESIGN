# v10 幾何精度調校計畫（平行度／垂直度）

適用：`output/v10/CNC_v10.FCStd`。行程 X 300、Y 400、Z 100 mm。目標：路徑精度 ±0.02 mm。
狀態：規畫稿，尚未改模型。文中的調整機構是 v11 的設計建議。
調校動畫：`output/v10/CNC_alignment_v10.html`（由 `freecad/v10/04_make_alignment_html_v10.py` 產生）
說明用簡報：https://claude.ai/artifact/3cdtpRruRKYex8GqvJFjZC （私人連結，需由擁有者分享後他人才能開）

## 1. 原則

1. **同一個零件、同一次裝夾能決定的關係，靠加工精度，不調。**
   做法是在零件上銑出基準肩，線軌或滑塊靠肩鎖附。
2. **跨多個零件累積出來的關係，留調整量，量測後再打定位銷。**
   定位銷孔在零件上只預鑽底孔，調好、鎖緊後現場配鉸（兩件一起鉸到 H7），再打銷。
   銷的功用是「記住調好的位置」，不是「決定位置」。
3. **治具板最後由機台自己銑一刀**，板面就自動平行於 X、Y 運動平面。
   銑的是鎖在工作台上的治具板，不是工作台本身：v10 的刀尖最低只到台面上方 20 mm，X 行程 300 mm 也小於台面寬 440 mm。
4. 每台機留一張量測紀錄表（第 6 節），量產時才看得出哪個零件或哪個工站在漂。

## 2. v10 各項幾何關係的歸類

| # | 幾何關係 | 由誰決定 | 歸類 | 做法 |
|---|---|---|---|---|
| 1 | Y 兩支線軌互相平行 | 工作台底面（單一零件） | 加工 | 工作台底面銑一道基準肩，主軌靠肩；副軌用跨橋錶對主軌 |
| 2 | Y 四顆滑塊成一直線 | 基準底板（單一零件） | 加工 | 底板銑一道基準肩，主側兩顆滑塊靠肩；副側滑塊浮動，跑全行程後鎖緊 |
| 3 | X 兩支線軌互相平行 | X 底板前面（單一零件） | 加工 | 下軌（z250）靠基準肩；上軌用跨橋錶對下軌 |
| 4 | Z 兩支線軌互相平行 | X 滑座板（單一零件） | 加工 | 同上 |
| 5 | Z ⊥ X（正面看，XZ 面） | X 滑座板：X 滑塊肩 ↔ Z 線軌肩 | 加工 | 兩道肩同一次裝夾加工，圖面標垂直度 0.01/200；組裝後只驗不調 |
| 6 | **X ⊥ Y（俯視，XY 面）** | 底板 ↔ 腳座 ↔ 立柱 ↔ X 底板 | **調整＋配銷** | 龍門整體繞 Z 微轉，調好後腳座與底板配鉸打銷 |
| 7 | **Z ⊥ Y（側面看，YZ 面）** | 同上，再加立柱（鋁擠）本身 | **調整＋配銷** | 腳座底下前後加墊片，改變龍門前後傾 |
| 8 | X 運動 ∥ 治具板面（左右高低） | 兩支立柱的長度差 | 自銑 | 不調。治具板自銑後自動消除 |
| 9 | 主軸軸線 ∥ Z 運動 | 主軸夾座 ↔ Z 滑板，加主軸外殼本身 | 調整 | 夾座與 Z 滑板之間墊片（前後傾）、螺絲孔間隙內微轉（左右傾） |
| 10 | 螺桿 ∥ 線軌（三軸） | 螺帽座、支撐座 | 組裝手法 | 不影響路徑精度，影響壽命與順暢度。見 4.6 |

真正需要「量了再調」的只有第 6、7、9 三項，其他都是「量了確認」。

| 工具 | 規格 | 用途 |

| 磁性錶座＋萬向臂 | 小型，能夾在 Z 滑板或主軸夾座上 | 把錶固定在主軸側 |

| 跨橋量具（自製） | 一塊鋼塊靠在主軌側面滑行，上面夾千分錶去碰副軌側面 | 兩軌平行度 |
| ER11 檢驗棒 | Ø6 或 Ø7、露出約 80 mm、圓筒度 0.003 以內 | 主軸偏擺、主軸 ∥ Z |
| 不鏽鋼墊片組 | 0.01／0.02／0.03／0.05／0.1 mm | 腳座、主軸夾座墊調 |
| 扭力扳手 | 涵蓋 M4–M8 | 線軌螺絲依序定扭力，否則量到的值不會重現 |
| 手提鉸刀＋鑽模襯套 | 配合定位銷徑（例如 Ø6 或 Ø8 H7） | 現場配鉸銷孔 |

| 工具 | 用途 |
|---|---|

### 驗收用（可租借或外包）

| 工具 | 用途 |
|---|---|
| 循圓測試儀（ballbar） | 十幾分鐘量出 XY 垂直度、背隙、伺服不匹配，最貼近「路徑精度」這個規格 |
| 雷射干涉儀 | 螺桿導程誤差、定位精度。首台或抽驗即可 |

沒有循圓儀時，用試切件代替：銑一個方＋圓的試件，送三次元量測。

## 4. 流程

每一步量測都固定同一個做法：**錶裝在主軸側（Z 滑板），基準件放在工作台上**。
直角尺本身的誤差用翻轉法消除：量一次，直角尺翻 180° 再量一次，兩次取平均。

### 4.1 進料檢驗（花崗石平台上）

- 基準底板、X 底板、工作台底面：線軌安裝面平面度 ≤ 0.01。線軌會順著安裝面變形，這個值直接變成路徑誤差。
- 各基準肩直線度 ≤ 0.005（錶沿肩滑行）。
- 立柱兩端面：必須銑過，對側面垂直度 ≤ 0.02/160。鋸切端面的垂直度不夠，會把墊片調整量用光。
- X 滑座板：兩道肩的垂直度 ≤ 0.01/200。

### 4.2 Y 軸

1. 工作台翻面。主軌靠基準肩，用側推塊頂住，螺絲由中間往兩端、分兩輪鎖到定扭力。
2. 副軌輕鎖。跨橋錶沿主軌滑全長，副軌側面讀值變化 ≤ 0.005，邊量邊鎖。
3. 基準底板：主側兩顆滑塊靠肩鎖緊，副側兩顆不鎖。
4. 工作台裝上，手推全行程來回數次，在行程中段鎖副側滑塊。推力應全程均勻。
5. 裝 Y 螺桿（4.6）。

### 4.3 龍門次組立（花崗石平台上）

1. X 底板裝線軌：下軌靠肩，上軌跨橋對下軌 ≤ 0.005。
2. 兩支立柱＋腳座＋X 底板在平台上組起來，腳座底面貼平台。
3. 直角尺立在平台上，錶沿 X 底板前面上下滑：先看兩支立柱位置的前後傾是否一致（差值就是扭曲），差太多先在這裡處理。
4. 裝 X 螺桿、X 滑座板、Z 軸。

### 4.4 龍門上機：X⊥Y 與 Z⊥Y（最關鍵的一站）

1. 龍門放上基準底板，腳座螺絲只上到貼合、還能推動的程度。
2. **X ⊥ Y**：直角尺平放在工作台上。
   - 走 Y，錶碰直角尺的 Y 向邊，輕敲直角尺直到全程讀值不變。
   - 走 X，錶碰直角尺的 X 向邊，讀值變化除以量測長度就是垂直度誤差。
   - 用腳座前方的頂推塊把一支立柱往後推。柱距 640 mm，推 0.01 mm 約改變 16 µrad，等於 X 走 300 mm 差 0.005 mm。
   - 推左柱與推右柱的轉向相反，所以只從前方推，兩個方向都調得到。（基準底板後緣與腳座後緣齊平，後方沒有位置放頂推塊。）
   - 推的時候另放一支錶直接頂在腳座上看移動量，不要靠螺絲轉幾圈去估。
   - 目標 ≤ 0.010/300。
3. **Z ⊥ Y**：直角尺立放（或用圓柱直角尺）。
   - 走 Z 100 mm，錶碰直角尺朝 Y 的那一面，讀值變化就是前後傾。
   - 在腳座前緣或後緣墊墊片。腳座含前凸緣深 220 mm，墊 0.01 mm 約改變 45 µrad，等於 Z 走 100 mm 差 0.005 mm。（v10 現況無凸緣時深 180 mm，對應 56 µrad。）
   - X 移到 −150、0、+150 三個位置各量一次。三處不一致代表兩支立柱傾角不同，左右腳座要分開墊。
   - 目標 ≤ 0.010/100。
4. **Z ⊥ X**：同一個直角尺轉 90°，走 Z，錶碰朝 X 的那一面。這項只驗不調，目標 ≤ 0.010/100。超差代表 X 滑座板加工不良。
5. 腳座螺絲依序鎖到定扭力。**鎖緊後第 2、3 項全部重量一次**，鎖緊常會讓數值跑掉。
6. 合格後，腳座與基準底板配鉸銷孔（每個腳座凸緣 1 支，兩支相距 640 mm），打入定位銷。
7. 打銷後再量一次並記錄。

### 4.5 主軸

1. 裝檢驗棒，轉主軸量偏擺（近端 ≤ 0.005、遠端 ≤ 0.010），先確認筒夾與主軸沒問題。
2. 錶固定在工作台上，碰檢驗棒側面，走 Z 約 60 mm。分別從 X 向、Y 向各量一次。
   v10 的筒夾螺帽端面到台面只有約 90 mm，檢驗棒露出 80 mm 時 Z 只能走約 60 mm。
   為了扣掉檢驗棒本身的偏擺，每個方向都把主軸轉 180° 再量一次取平均。
3. 前後傾（Y 向）：主軸夾座與 Z 滑板之間墊片。左右傾（X 向）：鬆開夾座螺絲在孔隙內微轉。
4. 目標 ≤ 0.015/100（量 60 mm 時為 0.009）。這顆氣冷主軸的外殼對軸心本來就不是精密基準，所以一定要量，不能只靠夾座加工精度。
5. 合格後夾座與 Z 滑板配鉸打銷。

### 4.6 螺桿對線軌（三軸相同）

1. 固定側支撐座、螺帽座都先輕鎖。
2. 把滑座移到最靠近固定側支撐座的位置，鎖緊螺帽座；螺桿此時最不容易被別彎。
3. 移到行程另一端，確認手轉扭力沒有明顯變重，再鎖其餘螺絲。
4. 全行程來回，看伺服驅動器顯示的負載率，全程變化應很小。變化大就代表螺桿與線軌不平行，回到步驟 1。

螺帽座與支撐座建議**不打銷**或最後才配銷：它們的位置應該由螺桿自己找到，不該被銷強迫。

### 4.7 治具板自銑與最終驗收

1. 所有幾何項目合格、打完銷之後，把治具板鎖在工作台上，用機台自己輕銑一刀（0.05–0.1 mm）。
2. 錶裝主軸側，走 X、Y 全行程掃治具板面，讀值變化 ≤ 0.010。
3. 重複定位：錶頂住台面上的擋塊，同方向靠近 10 次，散佈 ≤ 0.005；再量反向靠近的差值（背隙）。
4. 循圓測試或試切件驗收，結果填入紀錄表。
