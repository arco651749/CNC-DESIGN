## 走線路徑（機構 session 定案，全程在機台外面，不用拖鏈，與運動浪管完全分開）
1. 立柱電箱出口在後牆左下（x -380..-300，z 250..290，風扇下方）。
2. 往後穿過後護罩（機構開防水接頭孔，約 (-340, 570, 270)），出到護罩外面。
3. 沿護罩外側到左後腳（x -470），沿腳後面往下到 z -640。
4. 沿左下側樑外側（x < -492.5）往前到左前腳，再沿前低樑前面（y < -600）往右到 x -150。
5. 向上進**底座電箱底面**防水接頭，在 **(x -150, y -620, z -510)**（箱底 z 由 -520 改成 -510，已開 D32 孔）。
- 全長約 2.8 m，下料 3.3 m。動力線 F1/F2/F3 + PE 走一條 PA 浪管（內徑 ≥ 32）；控制線 F4（屏蔽）另走小浪管，兩者相距約 50 mm。
