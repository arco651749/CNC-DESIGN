# v14 浪管與線束配置（2026-11-28）

每一段浪管兩端都用 KSS PAQ 接頭（固定頭）鎖在鈑金上；固定頭之間的線、管都走在封閉的盒子或線槽裡。
模型：`freecad/v14/01_v14_toolhead.py`（零件）、`22_conduit_v14.py`（浪管形狀與干涉檢查）。

## 2. 集線盒與線槽

- **X 滑座集線盒 `X_cable_box`**：SPHC t1.6 焊接盒，上蓋 M4 鎖在拉帽上，粉體塗裝。盒子分三段：
  - 立管：在滑座後方。
  - 上段：跨過滑座頂。
  - 前段：在 Z 馬達右側，蓋在 Z 滾輪座上方。

  盒子用兩片 t3 角鐵固定：後角鐵用原 X 臂的 4 個孔，前角鐵用原托架的 2 個孔。Z 馬達線（動力、煞車、編碼器）從前段左壁的 M25 防水固定頭出線。這個盒子取代了以下零件：原 X 臂與夾座、滑座托架與夾座，以及繞過 Z 馬達的那一段開放浪管。
- **工作台後側線槽 `Table_cable_duct`**：t1.6 U 型槽，有蓋，裝在工作台後面。高度 z 86–110，低於台面，位置在 Y 馬達座後方、Y 馬達上方。
  - 用 4 片角鐵鎖在台後端面，避開 T 槽出口；左側段另用 2 片角鐵鎖在台左側面。
  - 收集：
    - Y 馬達的動力線與編碼器線：在 x 45 從底板的護線圈進槽。
    - 鏡蓋氣缸的 2 根 Ø4 氣管和磁簧開關線：從左側段上方進槽。
  - 匯到右後集線盒 `Table_cable_end_box`，再進 Y 浪管。
  - 集線盒分兩段高度：
    - x < 252 的低段頂部 z 120，讓開 X +182.5、Z -50 時 ER11 螺帽掃過的區域。
    - 高段頂部 z 153，包住接頭螺帽。
  - 集線盒在 Y +150 時位於 Y 固定段直下浪管的前方，間隙 5.75 mm。

## 4. 待定事項

- **冷卻液管**：目前只畫到左側護罩頂的穿板接頭（06），還沒有接到工具頭的噴嘴。有兩個做法要業主決定：
  - 和線一起走 XA、ZB：12 mm 管會讓 XA 的填充率到約 55 %，兩段要改用 PA-36。
  - 另走一條獨立的冷卻管路。
- KSS PA 浪管頁（內徑、外徑、最小彎曲半徑）和固定座頁：資料到手後再核對 R 55 / R 60 / R 80，以及填充率。
- M25 固定頭與 PAQ 接頭本體目前是估計尺寸，要依廠商圖面確認。
